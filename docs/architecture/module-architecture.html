Layer 2 — 核心层 (hydra-core)

▸ 模块 A：Agent 定义
CRATE hydra-core / agent/
文件
mod.rs execution.rs orchestrator.rs reviewer.rs
核心 trait 定义
#[async_trait]
pub trait Agent: Send + Sync {
    fn id(&self) -> AgentId;                     // u64, 全局唯一
    fn kind(&self) -> AgentKind;                 // Execution / Orchestrator / Reviewer
    fn state(&self) -> &AgentState;              // 只读快照
    fn branch(&self) -> Option<&str>;           // git 分支名
    fn worktree(&self) -> Option<&Path>;        // worktree 路径

    async fn run(&mut self, resources: ResourceHandle) -> Result;
    async fn on_command(&mut self, AgentCommand) -> AgentResponse;
}
类型定义
类型字段说明
AgentIdu64全局唯一，单调递增
AgentKindenumExecution / Orchestrator / Reviewer / Custom
AgentStateid, kind, status, created_at, updated_at共享可观测状态
AgentStatusenumCreated / Running / Paused / Completed / Killed / Failed
AgentSpeckind, model, files, taskspawn 时的参数
AgentOutcomesuccess, edited_files, summary, metricsrun() 返回值
AgentMetricsturns, edits, tokens, duration, compile, tests运行指标

通信流汇总 (Communication Flow Summary)

完整调用链：用户提交任务 → Agent 完成 → 分支合并
// 1. 用户通过 CLI 提交任务
hydra run "添加用户注册接口"
  │
  ▼
// 2. CLI 调用 ResourceManager
ResourceManager::spawn(AgentKind::Orchestrator, spec)
  │
  ▼
// 3. OrchestratorAgent.run() 启动，收到 SubmitTask 指令
OrchestratorAgent.on_command(AgentCommand::SubmitTask { description })
  │
  ▼  内部调用
// 4. Orchestrator 解析任务，生成 ExecutionAgent
resources.spawn(AgentKind::Execution, AgentSpec { files: ["src/auth.rs"], model: "claude" })
  │
  ▼
// 5. ResourceManager 调用 hydra-workspace 创建 worktree
HydraWorkspaceManager::create_for_agent(id, "main")
  │  内部调用
  ▼
// 6. ISO-Framework Manager::create() 执行
iso_code::Manager::create(branch, path, options)
  │  返回
  ▼
// 7. ResourceManager 创建 ExecutionAgent，spawn 异步任务
tokio::spawn(agent.run(&resources))
  │
  ▼
// 8. ExecutionAgent 内部循环：LLM + Tool
loop {
    response = provider.chat(chat_request)      // ← atomcode LlmProvider
    tool_calls = parse_tool_calls(response)
    for call in tool_calls {
        tool = tool_registry.get(call.name)     // ← hydra-core ToolRegistry
        result = tool.execute(tool_ctx, args)   // ← cwd = worktree
        event_tx.send(AgentEvent::ToolCall)     // ← 发送事件
    }
}
  │
  ▼  事件流
// 9. EventBus 扇出到所有订阅者
EventBus::broadcast(AgentEvent::ToolCall)
  ├─▶ OrchestratorAgent.event_rx
  ├─▶ hydra-daemon (REST → VSCode / Web)
  ├─▶ hydra-cli TUI
  └─▶ 其他订阅者
  │
  ▼  决策
// 10. Orchestrator 评估质量，决定 promote
OrchestratorAgent 内部 LLM 决策
  → resources.send_command(id, AgentCommand::Kill)   // 对其他 Agent
  → resources.send_command(id, AgentCommand::InjectHint)  // 注入提示
  │
  ▼
// 11. ExecutionAgent 完成，发出 Completed 事件
event_tx.send(AgentEvent::Completed { agent_id, outcome })
  │
  ▼
// 12. Orchestrator 决定 promote，调用 git merge
HydraWorkspaceManager::cleanup_agent(id, outcome)  // 保留分支
  │
  ▼
// 13. 用户通过 hydra promote 合并到 main
hydra promote 1 --to main
  │
  ▼
// 14. CLI 调用 ResourceManager
ResourceManager::send_command(1, AgentCommand::ReviewTarget { ... })

dashboard ────────────────────────┤

                          ┌───────────────┐
                          │  hydra-core   │  ← 核心，无上层依赖
                          └───────┬───────┘
                                  │
                    ┌─────────────┼─────────────┐
                    │             │             │
                    ▼             ▼             ▼
              hydra-workspace   provider/     tools/
              (ISO-Framework    (OpenAI/      (edit/bash/
               fork)            Anthropic/    read/...)
                                Ollama)

// hydra-core 只依赖：
//   - hydra-workspace（worktree 操作）
//   - atomcode-core（LLM / Tool 基础 trait）
//   - 标准库 + tokio + serde

// 禁止的依赖（违反架构）：
//   ❌ hydra-core → hydra-daemon（core 不知道 daemon）
//   ❌ hydra-core → hydra-cli（core 不知道 CLI）
//   ❌ hydra-workspace → hydra-core（workspace 不知道 Agent）
//   ❌ Agent 直接持有另一个 Agent 的引用（通过 EventBus 通信）
